First project on the site, the site itself. Made with [**Astro**](https://astro.build/), [**TailwindCSS**](https://tailwindcss.com/), and hosted on [**Github**](https://github.com/RyuukoAki/RyuukoAki.github.io), the site itself is always a work in progress. I certainly don't consider myself a front-end dev, but I'm quite happy with how this site turned out. I will be continuously improving this site, adding new features, and updating the design as I learn more about web development. <br/><br/>
I'd like to add more projects to the site, the ability to filter and sort projects by date and tags, and potentially a dev log for *Spellbound* (or any other development projects) in the future.<br/><br/>
Fun fact: the site has both light and dark mode, determined by the preference saved in your browser. It also features an animated background that I think, is real neat <br/>
Huge thanks to the Astro and Tailwind communities for their amazing documentation and tutorials.
